selected write-ups

How the findings worked and how they were fixed, with all target detail removed.

Reflected XSS via attribute injection in a login page P3 ✓ rewarded

summary: User input was written into an HTML attribute on a login page without encoding, so a crafted link could break out of the attribute and run script in the victim's browser.

impact: Script executed in the context of the page for whoever opened the link, with every action available to a signed-in user.

fix: Context-aware output encoding, strict input validation and a CSP.

Fix bypass: the same issue still live on production P3 ✓ rewarded

summary: The report was closed after a fix went into a test environment. I demonstrated the same execution on production, which showed the fix had not covered the code path that mattered.

impact: The vulnerability stayed exploitable in the environment that carries real users, after it had been marked handled.

fix: Patch the shared code path rather than a single environment, and verify the fix on production.

Reflected XSS across an authentication flow spanning several domains P3 ✓ rewarded

summary: Input in the authentication flow was reflected without encoding, and the flow crossed several domains, so one injection point reached more than one origin.

impact: Wider blast radius than a single-domain reflection, in the part of the app where sessions are created.

fix: Encode output by context on every domain that shares the flow, and validate input at the entry point.

Reflected XSS in a test-environment management interface P3 ✓ rewarded · resolved

summary: A management interface on a test environment reflected a request parameter into an HTML response. Reported, fixed by the product team, and closed as resolved.

fix: Context-aware output encoding and parameter allowlisting.

WAF keyword-filter bypass: reflected XSS in a management interface P3 ✓ accepted · points

summary: A web application firewall blocked the obvious form of the payload by filtering a keyword. An alternative syntax reached the same object and executed, so the filter was not a real control.

impact: Script execution in the browser of an administrator who opened a crafted link, on an interface that manages production map services.

fix: Encode output by context. Keep WAF rules as a speed bump, never as the thing standing between input and the browser.

Unauthenticated information disclosure from an outdated internal system P3 ✓ accepted

summary: An issue-tracking system on a test asset was running a version with a known flaw and was reachable without credentials. It returned internal information to an unauthenticated request.

impact: Internal records readable by anyone who found the host, with no login and no interaction from a victim. Test assets are a common path into the real thing: they hold copied data and share naming and access patterns with production.

fix: Patch the system, take test assets off the public internet, and treat non-production exposure as a production risk.
